## Load it

```python
from seahorse.data import load_released_dataset

splits = load_released_dataset("comcat_california")  # config "native"
train, val, test = splits["train"], splits["val"], splits["test"]
```

```bash
python -m seahorse fit --preset poisson_gmm --dataset comcat_california --out runs/comcat_california_poisson
```
