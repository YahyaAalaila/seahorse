## Rebuild it

The publisher's licence does not allow hosting the data as a stand-alone dataset. The repository ships a rebuild script, a verifier and the expected split hashes:

```bash
huggingface-cli download seahorse-stpp/nyc_bikeshare_legacy_stpp --repo-type dataset --revision 51adba249f62cce395c2a8f7930fa551c4776e17 --local-dir nyc_bikeshare_legacy_stpp
cd nyc_bikeshare_legacy_stpp
pip install -r rebuild/requirements.txt
python rebuild/rebuild.py --out ./legacy_out
python verify.py --out ./legacy_out
```

Please do not re-host the rebuilt files. The exact arguments and the expected outputs are on the [dataset card](https://huggingface.co/datasets/seahorse-stpp/nyc_bikeshare_legacy_stpp).
