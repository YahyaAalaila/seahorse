## Rebuild it

The records contain address-level emergency call types, so the data are not redistributed. The repository ships a rebuild script, a verifier and the expected split hashes:

```bash
huggingface-cli download seahorse-stpp/seattle_fire911_stpp --repo-type dataset --revision 739d52ceaf9547fcce6fb85b2ee35b967c115362 --local-dir seattle_fire911_stpp
cd seattle_fire911_stpp
pip install -r rebuild/requirements.txt
python rebuild/rebuild.py --out ./seattle_out
python verify.py --out ./seattle_out
```

Please do not re-host the rebuilt files. The exact arguments and the expected outputs are on the [dataset card](https://huggingface.co/datasets/seahorse-stpp/seattle_fire911_stpp).
