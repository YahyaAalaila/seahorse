## Rebuild it

The publisher's licence does not allow hosting the data as a stand-alone dataset. The repository ships a rebuild script, a verifier and the expected split hashes:

```bash
huggingface-cli download seahorse-stpp/nyc_bikeshare_2019_stpp --repo-type dataset --revision 4c25097611ee3e6226a7c82343ed6a52ae689617 --local-dir nyc_bikeshare_2019_stpp
cd nyc_bikeshare_2019_stpp
pip install -r rebuild/requirements.txt
python rebuild/rebuild.py --out ./bikeshare_out
python verify.py --out ./bikeshare_out
```

Please do not re-host the rebuilt files. The exact arguments and the expected outputs are on the [dataset card](https://huggingface.co/datasets/seahorse-stpp/nyc_bikeshare_2019_stpp).
